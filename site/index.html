kanban

A live board of every Claude Code session on your Mac

Each card is a running session with its goal and what it is doing right now. Cards link when one session spawns, forks or runs another as a subagent, and messages between them animate across the board.

What it does

  • Answer in place

    Open a card for its conversation, drawn from the transcript. Approve a permission or answer a question and watch the session move on.

  • The real terminal

    One toggle from the conversation to the session's live terminal. Type straight into it.

  • See sessions talk

    Hover a message in the rail to light up the sender, the receiver and the arc between them.

  • Subagents at a glance

    Every subagent a session runs, laid out in a grid and highlighted from the session's pill.

  • Find what needs you

    Search, filter by activity, and press J to jump to the next session waiting on you.

  • Start new sessions

    Pick a project and a prompt in the new session dialog, or fire one off from a quick prompt.

  • Annotate the board

    Markdown sticky notes, stickers, and project regions you draw and recolour.

  • Ask the board

    Press / to leave a comment and the board agent answers, using only the board's own tools.

How it works

Reads ~/.claude

Sessions, transcripts, subagents and messages come straight from Claude Code's own state directory. There is no database to set up or keep in sync.

Nothing leaves your Mac

A small Node server on 127.0.0.1 serves the board. No account, no telemetry, no hosted backend.

Drives real sessions

Background sessions and sessions in cmux panes are attached through their real terminals, so what you type is what Claude Code sees.

Install

Requirements

  • macOS
  • Node 24 or newer
  • Claude Code on PATH
  • cmux, optional

Run it

git clone https://github.com/kranners/kanban.git
cd kanban
npm install
npm run build
KANBAN_AUTH=off npm start

Then open http://127.0.0.1:7420.

A note on security

kanban is a remote terminal into every Claude Code session on the machine: whoever reaches it can type into those sessions with your full reach. It binds to loopback by default and refuses KANBAN_AUTH=off on any other address. Read SECURITY.md before exposing it anywhere else.
